Vì sao dùng AHV CLI?

Xây cho developer đang phải chuyển tab, copy-paste giữa ChatGPT và terminal cả ngày.

⚡

Zero setup

curl … | bash → gõ ahv. Không Docker, không DB. Chỉ cần Node ≥22 và API key.

🧰

Tools tích hợp

bash, file_read, file_write, grep — model gọi trực tiếp, kết quả cắt bounded để không blow context.

🔀

Multi-provider

Anthropic, OpenAI, DeepSeek, hoặc bất kỳ endpoint OpenAI-compat. Đổi bằng 1 flag.

💾

Session persist

Mỗi session lưu tại ~/.ahv/sessions/. Resume bất cứ lúc nào bằng ahv --resume <id>.

🇻🇳

Tiếng Việt-first

System prompt + UI tiếng Việt mặc định. Set language: "en" trong config nếu cần English.

🔌

Plugin-friendly

Mọi tool + provider theo cùng 1 interface. Cài thêm từ npm/GitHub qua dsh plugin add. Registry admin ở /admin tự track version pinned vs latest.

🔑

Subscription providers

Đã có ChatGPT Pro/Codex, Claude Pro, Grok Premium? Login OAuth 1 lần qua browser, dùng subscription làm LLM provider — không phải trả API token thêm. ahv login url grok → click browser → xong.

🤖

Bot-ready

JSONL adapter chuẩn cho Telegram/automation bot: ahv run --prompt-file X --output jsonl --session-id ID. Session id caller-supplied, genuine resume, exit code taxonomy 0/1/2/124. Bot pin theo git tag (v0.2.0-p2).

Providers hỗ trợ sẵn

Cả 3 built-in. Config qua ~/.ahv/config.json hoặc env var.

🅰️

Anthropic

Claude Opus, Sonnet, Haiku. Streaming + tool_use native. Env: ANTHROPIC_API_KEY.

claude-opus-4-7 claude-sonnet-4
🟢

OpenAI

GPT-5.x, GPT-4o. Cũng dùng được cho mọi endpoint OpenAI-compat qua baseURL. Env: OPENAI_API_KEY.

gpt-5-sol gpt-4o custom baseURL
🔷

DeepSeek

DeepSeek-R1, DeepSeek-V3. Alias OpenAI-compat trỏ vào api.deepseek.com. Env: DEEPSEEK_API_KEY.

deepseek-reasoner deepseek-chat

Cần provider khác (Google Gemini, Groq, Together, Ollama local…)? Trỏ baseURL vào endpoint OpenAI-compat của họ. Native adapter riêng có thể viết plugin — Phase 2 sắp mở.

Plugin cài sẵn

Cài ahv là có ngay ~50 plugin. Base dsh mang 40 plugin cốt lõi (shell, fs, web, subagent…); AHV thêm 10 plugin nữa cho toolbelt xịn ngay từ đầu. Full catalog live tại admin CMS — track version pinned vs latest, auto-refresh mỗi 6h.

⭐ AHV bundle (10 plugin thêm)

🖥️

Persistent PTY

dsh-terminal + -terminal-bash + -tool-terminal. Shell session sống xuyên tool call. Dùng cho SSH lâu dài, tmux flow, script long-running. 6 tool: terminal_open/send/read/signal/close/list.

🧬

Self-modification

cordis-host-runner + tool-cordis. Agent tự inspect runtime của chính mình và mount plugin ad-hoc in-memory. 5 tool: cordis_inspect/define/run/stop/undefine. Không ghi file, không survive restart.

🛒

Plugin Market

dshmarket — browse, search, one-click install 1.5k+ community plugin. Auto backup/restore, hot-reload. Chỉ active trong web mode: ahv web → Settings → Plugin Market. dsh-market/dsh-market ↗

🦸

Superpowers

superpowers-dsh — 14 curated skill: test-driven-development, systematic-debugging, brainstorming, writing-plans, executing-plans, subagent-driven-development, using-git-worktrees, dispatching-parallel-agents, verification-before-completion, code-review flow. Adapt từ obra/superpowers của Claude Code. Model gọi tự động qua skill_list / skill_load. LayneChai/superpowers-dsh ↗

🔑

Subscription providers

dsh-plugin-subscriptions — dùng ChatGPT (Codex Plus), Claude Pro, Grok Premium làm LLM provider mà không phải trả API token. OAuth login qua browser 1 lần (ahv login url grok), plugin tự mount route. Sau login là ahv models list thấy full catalog 15+ model từ subscription. V1ki/dsh-plugin-subscriptions ↗

🤖

Bot adapter

bot-runner + bot-startup (AHV built-in). Non-interactive JSONL streamer cho Telegram/automation bot: ahv run --prompt-file X --output jsonl --session-id ID. Subscribe session/event bus, emit taxonomy chuẩn (session_meta, assistant_delta, tool_status, assistant_final, turn_end, error). Exit code 0/1/2/124 theo bot spec. Session id caller-supplied + genuine resume. Contract pin: v0.2.0-p2 ↗

📦 Base bundle (40 plugin từ dsh)

⚙️

Shell & Filesystem

bash, pwsh, fs_read_file, fs_write_file, fs_search, str_replace_editor. Sandbox permissions + bounded output.

🌐

Web

web_search, web_fetch. Fetch tắt mặc định (SSRF risk); search bật khi có provider (bundle AHV tắt DeepSeek search — mount Brave/Tavily nếu cần).

👥

Subagents

subagent (spawn), subagent_fork (kế thừa history). Delegate task cho agent con — parallel hoặc isolated context.

📋

Todo & Plan

todo_write — model tự track checkbox realtime. plan-mode — plan trước khi run, user approve exit_plan_mode.

🎓

Skills

skill_load, skill_list. Skill = recipe YAML/MD cho task pattern lặp lại. Hot-reload không restart.

⚡

Workflow & Ralph

workflow (multi-step trong worker thread), tool-ralph (fresh-agent iterator max 64 rounds).

🎯

Goal & Compaction

goal-round-driver — set goal xuyên session. compaction-basic — tự nén context khi vượt threshold.

🔒

Sandbox & Permission

sandbox-policy + permission-presets. 3 mode: read-only, workspace-write (default), danger-full-access.

Plugin cũng auto-latest

AHV bundle đăng ký deps với semver caret (^1.18.0). ahv update chạy pnpm install, tự nhận bản minor mới. Admin CMS /admin hiển thị badge stale khi có bản major mới cần bump thủ công.

🏷️

Pin theo tag cho bot/production

git -C ~/.ahv/src checkout v0.2.0-p2 — lock version cụ thể, không auto-move. Bot team và integration downstream pin tag này, chỉ ahv update khi anh Hiếu bump.

🔄

Rollback dễ

git -C ~/.ahv/src reset --hard v0.2.0-p1 rồi pnpm install. Không có DB migration, không có server state — mọi thứ trong ~/.dsh giữ nguyên qua rollback.

Update ngay: ahv update. Chi tiết + rollback: GitHub Releases.
