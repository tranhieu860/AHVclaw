Vì sao

Bớt chuyển tab. Nhiều hơn ở trong repo.

Xây cho người đang copy-paste giữa ChatGPT và terminal cả ngày.

Zero setup

curl | bash rồi gõ ahv. Không Docker, không DB. Chỉ Node và một API key.

Tool native

bash, file, grep, browser, subagent. Model gọi trực tiếp. Output bị cắt để không nổ context.

Giữ session

Mỗi cuộc trò chuyện nằm ở ~/.ahv/sessions/. Resume bằng ahv --resume.

Tiếng Việt trước

Prompt và UI mặc định tiếng Việt. Đổi language: "en" khi cần.

Bắt đầu

Ba mươi giây.

Yêu cầu Node.js ≥ 22. Key xin tại /apply.
